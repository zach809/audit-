CWCA update proof

Version marker:
cwca-boomer-friendly-postclosure-reports-2026-06-19

What changed:
- Simplified the Post-Closure tab for easier use by non-technical staff.
- Replaced the Post-Closure chip/button filter rows with one clear dropdown filter panel.
- Post-Closure reminder cards are collapsed by default so the page does not feel flooded with forms.
- The Teams follow-up message is hidden until opened, with a Copy Teams Note button inside.
- Shortened the Post-Closure card form wording and changed Save Follow-Up to Save.
- Simplified the Reports tab by hiding the weekly review builder behind an optional expandable section.
- Hid the report format preview behind an optional expandable section.
- Kept all existing exports and diagnostics; this is a layout/clarity cleanup, not a Clio behavior change.
- Added an Internal Diagnostics export in Reports called Audit Logic Issues.
- The diagnostics report lists API errors, unclear evidence matches, direction-unclear communication rows, Clio notes access issues, and other Unknown audit rows.
- Each diagnostics row includes issue type, reason code, what happened, suggested debugging step, Clio matter link, proof link, last checked date, audit version, and any human review note.
- The diagnostics report is separated from the case-manager report so logic bugs do not get mixed into staff coaching.
- Added a Post-Closure Date Window filter: Current Window, Older Backlog, and All History.
- Current Window is now the default and shows reminders due in the last 45 days or next 45 days.
- Older one-year-old missed reminders stay available under Older Backlog instead of dominating the main queue.
- Post-Closure closed-matter detection now rejects Clio matters whose status says Open or Pending.
- Fixed Post-Closure visibility so the default view shows all 1-month, 6-month, and 12-month reminders instead of only currently due items.
- Refresh now repairs older Post-Closure data by backfilling any missing 1-month, 6-month, or 12-month reminder rows for stored closed matters.
- Touchpoint filters now show counts, so the dashboard makes it obvious whether 1 Month, 6 Months, and 12 Months are present.
- Refresh now reports reminder checks, new reminders, and repaired missing reminder rows.
- Added a responsible-attorney filter to the Post-Closure follow-up queue.
- The Post-Closure summary counts now respect the selected attorney and touchpoint filters.
- Added a Teams-ready copy-paste note for open post-closure follow-ups in the current filtered view.
- The Teams note groups open follow-ups by attorney and includes client/matter, touchpoint, status, due date, and Clio matter link.
- Fixed Post-Closure refresh so it searches Clio by close_date instead of relying only on status=closed.
- Post-Closure refresh no longer stops after the first empty Clio response; it tries safe fallback reads before giving up.
- Post-Closure accepts a matter as closed when Clio provides a close date, even if the returned status text is inconsistent.
- The refresh notice now says if any closed matters were skipped because Clio did not return a usable close date.
- Added a Post-Closure tab for internal closed-matter client follow-up reminders.
- Post-Closure creates 1-month, 6-month, and 12-month internal reminders from Clio close_date.
- Due dates that fall on weekends move to the next business morning.
- Staff can mark each reminder as In Progress, Completed, Unable to Reach, No Action Needed, or Issue Found.
- Staff can record contact method, issue type, note, and reviewed-by name inside CWCA only.
- Closed matters remain excluded from active audit views.
- Clio remains read-only. No client messages or Clio updates are sent.
- Appearance Filed now stays Not Due Yet until the 48-hour weekday review window has passed.
- After the 48-hour weekday review window passes, missing Appearance Filed proof becomes Needs Follow-Up instead of the vague EVIDENCE_NOT_CONFIRMED review state.
- Older saved Appearance Filed review rows are interpreted by the dashboard using the current 48-hour deadline, so stale rows can display Not Due Yet when they are not actually due.
- Older saved Appearance Filed review rows are prioritized for the next safe audit batches so CWCA refreshes the Clio communications evidence.
- Added Weekly Client Check-In as a new calendar-and-call audit item.
- Weekly Client Check-In only passes when a weekly check-in/courtesy/follow-up calendar event exists and a phone-call communication exists on that same Illinois-local date.
- Existing matters that were audited before this new item was added now get pulled back into the safe batch queue so the Weekly Client Check-In row is filled in.
- Weekly Client Check-In no longer counts as the initial Attorney Call.
- Same-day weekly check-in phone proof can be an inbound or outbound real phone communication, but not a missed call or SMS.
- Appearance Filed matching now recognizes the current appearance filing notification template subjects more broadly.
- Upcoming weekly check-ins show as not due yet until the same-day call window has passed.
- Matters tab now has inline Auditor Status controls on flagged/problem items.
- Auditor Status controls are collapsed by default and open only when clicked.
- Saving an Auditor Status writes only to CWCA's audit_review tables.
- Clio remains read-only. No Clio create/update/delete actions were added.
- Closed human review decisions are treated as no longer open on the matter card.
- After save, the matter card refreshes so resolved/no-action items disappear from Problems.
- The top matter badge is based on open items after human review.
- Dashboard proof links now redirect immediately to the matching Clio matter evidence area.
- Old /evidence/... proof links now redirect to Clio by default too.
- The internal evidence-detail screen is only available with ?details=1.
